# Fusion Table v0.2.3 — pantry, ratings, and the Android download

The hosted app and GitHub repository are public. Recipes remain template-generated and not kitchen-tested.

## What changed

- The header links to `/downloads/MealPlannerAU.apk`. That address stays the same. Replace the file when a new phone build is ready. The phone app does not use the network.
- Shop search lists supermarkets, grocers, butchers and markets. Petrol stations and unnamed convenience shops are left out. No shelf price is added, and an unknown price is not shown as zero.
- Tick what is already at home, then choose “I’m making this”. Oils, butter, flour and similar cupboard items stay on the pantry list. A shortfall is an amount still to buy, never a price. The week plan warns when the pantry will not cover the planned dinners.
- A recipe can be given one to five stars, and “won’t have again”, “might have again”, “will have again”, or “this is a new staple”. Those choices stay in this browser.

Shopping-list, pantry, planner, staple and shop-filter tests cover the new behaviour. Stock and prices remain unverified.

## Downloads

- `fusion-table-v0.2.3-source.zip` — complete tracked source, recipe catalogs, image assets, routes, tests, documentation, tooling and lockfile.
- `fusion-table-v0.2.3-cloudflare-worker.tar.gz` — compiled application and independent Cloudflare deployment instructions.
- `SHA256SUMS` — checksums for both archives.

Use Node.js 22.13.0+ and pnpm 11.25.0. Install with `pnpm install --frozen-lockfile`, then run `pnpm dev` or `pnpm build`. Map searches require internet access. Ingredient lists and authored recipe generation do not. Stock and prices remain unverified.
