# Fusion Table v0.2.2 — reliable shopping and local shop search

This release repairs the shopping flow after intermittent live map-service failures. The hosted app and GitHub repository are public.

## Fixes

- Keep the ingredient shopping list and CSV download available before a location is selected, while shops are loading, and when map search fails.
- Retry eligible transient map-provider failures once within a bounded time budget. Preserve provider cooldowns, rate-limit instructions and accurate errors when a search cannot complete.
- Queue a small number of simultaneous searches instead of immediately rejecting one visitor because another search is in progress.
- Handle HTML gateway errors, malformed responses and client timeouts with readable messages and recoverable controls.
- Cancel superseded location/shop requests and ignore geolocation callbacks after the location dialog is closed. Use the current radius when location lookup completes.
- Explain when a radius change requires a new search.

Exact distance filtering, OSM shop subtypes, pantry matching, unverified inventory labels, the deterministic recipe engines and the existing cookbook storage format remain in place. Added regression tests cover transient failures, concurrency, cooldowns, browser request errors and cancellation.

## Downloads

- `fusion-table-v0.2.2-source.zip` — complete tracked source, recipe catalogs, image assets, routes, tests, documentation, tooling and lockfile.
- `fusion-table-v0.2.2-cloudflare-worker.tar.gz` — compiled application and independent Cloudflare deployment instructions.
- `SHA256SUMS` — checksums for both archives.

Use Node.js 22.13.0+ and pnpm 11.25.0. Install with `pnpm install --frozen-lockfile`, then run `pnpm dev` or `pnpm build`. Map searches require internet access; ingredient lists and authored recipe generation do not require map-provider success. Stock and prices remain unverified.
