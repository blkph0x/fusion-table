# Fusion Table v0.2.1 — expanded barbecue catalog and public downloads

This release includes the full deterministic barbecue expansion and corrects the source/download access documentation. The GitHub repository and published release assets are **public**; the existing hosted Sites app remains **owner-private**. This documentation correction does not change either audience.

## Recipe expansion

- **20 new classics** preserve all 8 originals, giving **28 classics**. They cover brisket, pulled protein, ribs, sausages, skewers, reverse-seared and flank steaks, lamb chops, wings, whole chicken, turkey breast, pork belly, hot-smoked and whole fish, prawns, ready-cooked octopus, vegetable trays, grain bowls, hot dip and ready-to-eat cold platters.
- **16 new regional profiles** preserve all 8 originals, giving **24 regions**: Texas, Carolina, Kansas City, Argentine asado, Korean BBQ, Japanese yakitori, Cantonese char siu, Vietnamese grill, Turkish mangal, Greek souvlaki, Spanish plancha, Jamaican jerk, Indian tandoor, Mexican al pastor, Moroccan mechoui and South African braai.
- All **5 diets** remain supported: **672 classic/region pairings** and **3,360 classic/region/diet configurations**. The separate ingredient-led builder retains **23,400 compatible configurations** across 22 mains, 12 techniques, 20 regions and 6 sides.

Recipes use authored templates without runtime model calls or randomness. Every result carries the exact label **“Template-generated · not kitchen-tested”**. Methods distinguish cuts, plant adaptations, small portions, outdoor smokers and ordinary oven alternatives. Cold platters use commercially ready-to-eat products or fully cooked alternatives; no home raw-fish curing process is supplied. Nearby shop listings remain unverified for stock and prices.

## Release assets

| File | Contents |
| --- | --- |
| `fusion-table-v0.2.1-source.zip` | Complete tracked application source, recipe catalogs, images, server routes, tests, documentation, build tools and lockfile. |
| `fusion-table-v0.2.1-cloudflare-worker.tar.gz` | Compiled server/client assets and instructions for deployment with your own Cloudflare account and Worker name. |
| `SHA256SUMS` | Checksums for both archives. |

Use **Node.js 22.13.0+** and **pnpm 11.25.0**. Extract the source, then run `pnpm install --frozen-lockfile` followed by `pnpm dev` or `pnpm build`. Recipe generation requires no credentials. Live map searches need server routes and internet access.

See the [catalog](https://github.com/blkph0x/fusion-table/blob/v0.2.1/README.md) and [self-hosting guide](https://github.com/blkph0x/fusion-table/blob/v0.2.1/docs/SELF_HOSTING.md).
