# Fusion Table v0.2.4 — a different week from the same pantry

The hosted app and GitHub repository are public. Recipes remain template-generated and not kitchen-tested.

## What changed

- Planning a week uses a seed. The same diet, allergens, dislikes and pantry can come back as different dinners. Press Plan my week again for another spread.
- Each night offers a few other matching templates. Randomise replaces that night only. A choice that fails the recorded filters is not used.
- An omitted seed still produces the previous stable week. Hard filters are not relaxed. No shelf price is added.

Planner tests cover a stable unseeded week, a seeded change, a one-night swap, and a refused allergen choice. Stock and prices remain unverified.

## Downloads

- `fusion-table-v0.2.4-source.zip` — complete tracked source, recipe catalogs, image assets, routes, tests, documentation, tooling and lockfile.
- `fusion-table-v0.2.4-cloudflare-worker.tar.gz` — compiled application and independent Cloudflare deployment instructions.
- `SHA256SUMS` — checksums for both archives.

Use Node.js 22.13.0+ and pnpm 11.25.0. Install with `pnpm install --frozen-lockfile`, then run `pnpm dev` or `pnpm build`. Map searches require internet access. Ingredient lists and authored recipe generation do not. Stock and prices remain unverified.
